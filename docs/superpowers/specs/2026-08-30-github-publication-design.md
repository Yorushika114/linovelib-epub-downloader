# GitHub 发布与相对路径设计

## 目标

将项目作为 `Yorushika114` 账户下的私有 GitHub 仓库发布；仓库只包含可复现的源代码、测试与说明，不包含已下载小说、图片缓存、Python 缓存或临时诊断文件。

## 路径策略

所有项目自有目录均从项目根目录派生：下载缓存放在 `<项目根目录>/_tmp_dl`，默认 EPUB 输出放在 `<项目根目录>/download`。命令行 `--out` 保留为用户显式给出的路径。系统浏览器不是项目文件，不保存任何机器特定的安装绝对路径；需要时优先使用 `--browser-path`，再通过 PATH 查找浏览器。

## 发布范围

新增 `.gitignore` 排除运行产物和本地工具状态；README 更新为实际目录结构、安装与运行方式、相对路径规则和已知限制。保留现有功能与测试，不提交下载得到的正文或图片。

## 验证

新增针对项目根目录路径解析的单元测试，运行全量 `pytest`，检查 Git 暂存区不含被忽略的运行产物、且不含 Windows 盘符绝对路径，最后创建私有 GitHub 仓库并推送首个提交。
