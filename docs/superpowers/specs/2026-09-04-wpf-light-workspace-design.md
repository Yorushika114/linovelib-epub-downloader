# WPF 浅色阅读工作台 UI 设计

## 目标

在不改变下载、搜索、候选书目、进度事件或安全取消行为的前提下，重构 WPF 窗口的视觉层。界面应适合长时间查看章节队列和错误信息，文字锐利、状态清晰，并且不依赖网络或外部图片资源。

## 设计方向

采用浅色阅读工作台：暖白背景、蓝灰结构色、青绿色作为唯一的操作强调色。以本地渐变、微弱星点和半透明光晕提供轻小说氛围；这些装饰只存在于空白区域，不能置于文字、输入框、表格或日志之后。

不采用全屏二次元插画背景（会降低文本对比度），也不采用高饱和多色主题（会削弱下载状态的辨识度）。

## 布局

窗口分为三个纵向区域：

1. 顶部标题栏：应用名称、简短说明和当前任务状态。
2. 主操作区：左侧为带步骤提示的下载表单；右侧为任务概览卡，展示总体进度、完成/失败数量和当前提示。
3. 任务区：章节队列占主要高度；日志位于底部并可折叠，避免在非调试场景抢占页面。

候选书目搜索时，候选表替代章节队列，表头和行高沿用相同的可读性规则。

## 组件规范

- 所有输入、表格与卡片使用白色实体底和浅色边框；禁止把正文直接叠在装饰背景上。
- “开始下载”使用青绿色实心主按钮；“安全取消”为低强调轮廓按钮。
- 进度卡提供百分比、进度条和“已完成 / 总数”三种冗余信息。
- 章节状态以带底色的徽标呈现：等待为灰蓝、下载中为蓝色、完成为绿色、失败为红色。
- DataGrid 采用无竖线、低对比横向分隔、悬停高亮和更紧凑但不拥挤的行高。
- 日志为可展开的深色等宽文本面板；默认收起并显示最近一条日志摘要。

## 状态与错误处理

现有 `DownloadEventDto`、`DownloaderBridge` 和下载事件的字段语义保持不变。UI 只根据既有事件更新状态、进度、章节行与日志。搜索、运行、取消和失败时必须恢复恰当的按钮可用状态。

## 验收

1. 现有 WPF 功能保持：搜索、选择候选、开始、安全取消、实时章节状态、进度和日志。
2. WPF 项目在隔离输出目录中可零警告构建。
3. 自动化测试覆盖用于更新任务概览和状态样式的公开视图状态。
4. 实际启动窗口后检查：主文字位于实体浅色表面、日志默认折叠、列表状态清晰可辨。
